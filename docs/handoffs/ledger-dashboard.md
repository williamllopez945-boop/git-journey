## Completed changes

- `trading_agent/dashboard.py`:
  - `build_dashboard()` (pure) → view dict: headline status
    (HALTED > CAPS BINDING > APPROVAL > NO ACTION), tiles, cap usage, UTC
    timeline marks, blocked-by-gate bars, research (one per asset, max 4),
    latest backtest note.
  - `render_html()` → self-contained page in the Continental theme, all
    logged text HTML-escaped.
  - `latest_backtest_note()` → newest `backtest_*.md` and its first heading.
  - `main()` CLI: reads `cycle_log.json`, `state.json`,
    `research_agent/research_log.json` as plain JSON (never through the
    writing stores); writes only `--out`, which must be a `.html` file
    that is not one of those inputs.
- Decisions and deviations from the canvas:
  - Account value and open positions are not persisted in the repo, so
    the risk-cap section uses an optional `--account-file` snapshot
    (`{"as_of","portfolio_value","positions":[{"asset","market_value"}]}`)
    and says so when it is absent.
  - The canvas's "Realized +$0.03" tile was replaced by "Executed" (count,
    buy/sell split, notional). Realized P/L needs cost basis
    (`reconcile_ledger.py`), not wired here.
  - The canvas's "Latest strategy change: ADOPTED" card became "Latest
    backtest note" (filename and heading). It does not parse the
    adopted/rejected verdict.
  - Added an "Approval" timeline row and an awaiting-approval tile.
  - Nav links to the other artboards were dropped (those pages aren't built).
  - Stop/take levels come from `exit_criteria` (4%/8%). The canvas still
    shows the old 10%/20% and a 2026-09-26 snapshot. This is stale canvas
    prose, not changed here.
